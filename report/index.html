Objetivo y scope

Modulo Flask independiente para consultar conceptos, registrar IaaS/PaaS/SaaS/FaaS, consultar progreso y contar clientes sin modificar el monolito Node.js.

Arquitectura

GUI de escritorio -> cliente SOAP -> HTTP/XML -> Flask -> psycopg -> PostgreSQL. El monolito sigue conectado directamente a PostgreSQL.

Contrato y operaciones

WSDL document/literal con XSD estricto: pendientes, clasificacion, progreso y estadisticas.

Seguridad y Fault

Las estadisticas exigen UsernameToken con hash PBKDF2. Los errores devuelven SOAP Fault sin stack traces ni secretos.

Plan de pruebas

Incluye casos positivos, duplicados HTTP 409, XML/modelo/concepto invalidos, autenticacion fallida y falla de PostgreSQL.
