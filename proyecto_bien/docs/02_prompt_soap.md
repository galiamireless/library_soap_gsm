# Prompt de contrato SOAP

Diseñar un servicio document/literal para clasificar conceptos Cloud asociados
a libros. El contrato debe exponer pendientes, registrar una clasificación,
consultar progreso y obtener estadísticas por modelo. Los modelos permitidos
son `IaaS`, `PaaS`, `SaaS` y `FaaS`; los campos deben estar calificados con el
namespace del servicio y los errores deben devolverse como SOAP Fault.
